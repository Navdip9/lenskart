**HTML, CSS, and Vanilla JavaScript**. 

Data stored in **LocalStorage**.


## User Side

- **Home** (index.html) – Welcome animation, slider, featured products, footer
- **Register** – Create account
- **Login / Logout** – Session in LocalStorage (currentUser)
- **Products** – All products, Add to Cart (login required)
- **Cart** – View, update quantity, remove, Place Order
- **Profile** – User details, total orders, total amount spent
- **Contact** – Contact form (stored in LocalStorage)

## Admin Side

- **Admin Login** (admin/admin-login.html) – Username: **admin**, Password: **admin123**
- **Dashboard** – Total Users, Products, Orders, Total Revenue, Contact Messages
- **Products** – Add / Edit / Delete products, category dropdown (13 categories)
- **Orders** – View all user orders

## Default Data

- **100 default products** (Lenskart-style eyewear) are added automatically when products list is empty.
- LocalStorage keys: `users`, `currentUser`, `adminSession`, `products`, `cart`, `orders`, `contacts`
